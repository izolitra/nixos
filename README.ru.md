# Моя конфигурация NixOS

В репозитории лежат настройки текущего ПК: пакеты и службы NixOS, Hyprland, тема Noctalia, клавиша скриншота и прежняя конфигурация Waybar. Версии Nixpkgs и Noctalia закреплены в `flake.lock`.

Репозиторий **публичный**. Не добавляй сюда пароли, VPN-профили, токены, SSH-ключи, содержимое `~/.config/Happ`, `~/.config/Throne` или `~/.aws`. Данные программ и личные файлы нужно резервировать отдельно.

## Как устроено

- `flake.nix` — список источников и конфигурация компьютера `desktop`.
- `hosts/desktop/` — системные настройки ПК, включая его диски и два монитора.
- `hosts/laptop/` — заготовка для будущего ноутбука с автоматической настройкой монитора.
- `home/hyprland.lua` — Ctrl+Shift+S для скриншота области только в буфер обмена.
- `home/desktop/noctalia-settings.toml` — точные настройки Noctalia с ПК. Файл `home/laptop/noctalia-settings.toml` сохраняет тему Dracula без привязки экрана блокировки к двум мониторам ПК.
- `scripts/restore-home.sh` — восстанавливает настройки в домашней папке, предварительно сохраняя старые копии.
- `scripts/save.sh` — забирает новые настройки из Noctalia, показывает изменения и после подтверждения отправляет их на GitHub.

## Включить эту конфигурацию на текущем ПК

Открой терминал в папке репозитория и выполни:

```bash
sudo nixos-rebuild build --flake .#desktop
sudo nixos-rebuild switch --flake .#desktop
./scripts/restore-home.sh desktop
```

Затем выйди из сеанса и войди снова. Noctalia теперь включена в системные пакеты. Старая копия, установленная через `nix profile`, пока может оставаться; удалять её стоит после проверки новой установки.

## Как сохранять свои изменения

Редактируй системные файлы и Hyprland **в этом репозитории**. После изменения NixOS применяй `sudo nixos-rebuild switch --flake .#desktop`. После изменения файла в `home/` запускай `./scripts/restore-home.sh desktop`.

Изменения, сделанные в окне настроек Noctalia, сохраняются самой программой в `~/.local/state/noctalia/settings.toml`. Чтобы скопировать их сюда, сохранить остальные изменения отслеживаемых файлов и отправить на GitHub, запусти:

```bash
./scripts/save.sh desktop
```

Скрипт покажет полный diff и спросит подтверждение перед отправкой. Новые файлы нужно добавлять вручную: `git add путь/к/файлу`. При первом пуше из терминала понадобится `gh auth login` или SSH-ключ: авторизация подключённого к этому чату GitHub не переносится в терминал.

На другом компьютере получи обновления через `git pull --ff-only`, затем примени их командами сборки и восстановления выше, указав имя нужного компьютера.

## Установка на ноутбук

Сначала установи NixOS обычным способом и клонируй этот репозиторий. Файл оборудования ПК переносить на ноутбук нельзя: там UUID дисков и настройки конкретного железа.

1. Скопируй `hosts/laptop/configuration.nix.example` в `hosts/laptop/configuration.nix`.
2. Скопируй с ноутбука `/etc/nixos/hardware-configuration.nix` в `hosts/laptop/hardware-configuration.nix`.
3. В новом `configuration.nix` выставь `system.stateVersion` из конфигурации, которую установщик создал **на ноутбуке**. Проверь загрузчик и сервисы, зависящие от железа. В `hosts/laptop/hyprland.lua` при необходимости настрой экран.
4. В `flake.nix` добавь `nixosConfigurations.laptop` по образцу `desktop`, заменив путь модуля на `./hosts/laptop/configuration.nix`.
5. Добавь и закоммить новые файлы. Проверь `sudo nixos-rebuild build --flake .#laptop`, затем выполни `sudo nixos-rebuild switch --flake .#laptop` и `./scripts/restore-home.sh laptop`.

После первого развёртывания на ноутбуке команда `./scripts/save.sh laptop` будет сохранять его настройки Noctalia. Файл оборудования ноутбука можно закоммитить для полного восстановления системы, предварительно просмотрев содержимое.
